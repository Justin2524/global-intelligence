关于这个知识库

Global Intelligence 是一个持续积累的私人研究与公开阅读档案。

从手机，保存一份报告

  1. 从 ChatGPT 复制完整 Markdown。日报需要十个编号的二级标题，周报至少两个二级标题，并保留来源链接。
  2. 以仓库 Owner 的 GitHub 账户登录，打开「发布新闻报告」。
  3. 选择 Daily 或 Weekly，填写日期，粘贴正文并提交。
  4. 等待 Issue 中出现「发布成功」评论与文章链接。失败时查看提示，修改原 Issue 或重跑失败的工作流。

内容原则

所有 Demo 都是格式示例，并非真实新闻。请核对 AI 生成内容的事实、日期与来源。本站仅存放原创摘要、知识分析及来源链接，不公开转载《经济学人》或其他媒体的付费全文。

分类与标签

在正文标题后增加「分类：macro, technology」与「标签：AI, 通胀」即可。分类支持 macro、technology、markets、geopolitics。未提供分类时，Daily 默认金融宏观，Weekly 默认国际政治与地缘风险；不会自动推断事实。
